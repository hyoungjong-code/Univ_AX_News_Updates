# Univ AX News Updates

대학·고등교육 분야의 AI 혁신 동향(대학 AX)을 웹에서 찾아 검증하고, 회의 자료에 바로 쓸 수 있는 브리핑으로 요약하는 [Claude Code](https://claude.com/claude-code) 스킬입니다.

스킬 이름: `higher-ed-ai-trends`

## 어떤 업무를 대신하나요

대학 기획처, 교수학습지원센터, 교육혁신 담당자가 정기적으로 하는 "AI 동향 모니터링"을 대신합니다.

| 사람이 하던 일 | 스킬이 하는 일 |
|---|---|
| 국내외 교육 매체·보도자료를 뒤져 기사 모으기 | 영어·한국어로 10~20회 검색해 기간 안의 후보 15건 이상 수집, 중복 병합 |
| 쓸 만한 기사 고르기 | 최신성·신뢰도·중요도를 각 10점으로 채점, 평균 9.5점 미만은 다음 후보로 교체 |
| 날짜·출처 확인하기 | 기사 원문을 직접 열어 발행일·매체·링크 확인, 문제 있는 기사 제외 |
| 회의용으로 요약하기 | 핵심 뉴스 5건을 건당 3문장으로 요약하고 핵심 키워드로 정리 |
| "그래서 우리 학교는?" 정리하기 | 해외 동향과 국내 정책·대학 사례 비교표 작성 |

작업은 세 역할이 순서대로 나눠 맡습니다.

- **리서처**: 꼼꼼한 어조로 후보를 수집합니다.
- **에디터**: 간결한 어조로 선별하고 요약하며 전체를 총괄합니다.
- **팩트체커**: 신중한 어조로 원문을 확인합니다.

다음과 같은 자료는 결과물에 넣지 않습니다.
- 출처 링크가 없는 기사
- 요청 기간 밖의 기사를 최신 뉴스로 소개하는 것
- 익명 소식통에만 기댄 보도
- 투자 조언이나 주가 전망

## 어떤 말을 하면 호출되나요

아래 같은 요청을 하면 스킬이 자동으로 호출됩니다.

- "대학 AI 트렌드 정리해줘"
- "고등교육 AI 동향 알려줘"
- "이번 주 대학 AX 소식 뭐 있었어?"
- "최근 3개월 대학가 생성형 AI 소식으로 기획처 회의 자료 만들어줘"
- "미국·영국 대학이 AI 때문에 시험 방식을 어떻게 바꾸는지 뉴스레터로 요약해줘"
- "올해 OpenAI·Anthropic·Google이 대학과 맺은 계약 사례 표로 정리해줘"
- "higher education AI trends this month"

기간을 말하지 않으면 최근 3개월로 조사합니다. "오늘", "이번 주", "이번 달", "올해"는 정확한 날짜 범위로 바꿔서 조사합니다.

## 설치 방법

### 모든 프로젝트에서 쓰기 (권장)

홈 디렉터리의 스킬 폴더에 설치합니다.

```bash
git clone https://github.com/hyoungjong-code/Univ_AX_News_Updates.git
```

```bash
mkdir -p ~/.claude/skills && cp -R Univ_AX_News_Updates/higher-ed-ai-trends ~/.claude/skills/
```

### 특정 프로젝트에서만 쓰기

프로젝트 폴더 안의 `.claude/skills/`에 복사합니다.

```bash
mkdir -p .claude/skills && cp -R Univ_AX_News_Updates/higher-ed-ai-trends .claude/skills/
```

설치한 뒤 Claude Code 세션을 새로 열면 적용됩니다. 이 스킬은 웹 검색과 웹 페이지 읽기 도구를 사용하므로, 두 도구를 쓸 수 있는 환경이 필요합니다.

## 결과물은 어떻게 생겼나요

기본 결과물의 구조는 아래와 같습니다. 예시 속 기관명과 내용은 형식을 보여 주기 위한 가상의 것입니다.

```markdown
# 고등교육 AI 동향 브리핑 (2026-07-29 ~ 2026-10-29)

> 조사 범위: 최근 3개월 · 글로벌 + 한국 · 고등교육 AI 전 분야 | 작성일: 2026-10-29
> 후보 22건 수집 → 기준 통과 7건 → 수록 5건
> **한 줄 요약:** 전교생 AI 교육이 정부 사업 요건이 되면서, 대학의 관심이 '도입'에서 '성과 검증'으로 옮겨 가고 있다.

## 핵심 뉴스 5선

### 1. ○○부, 전교생 AI 기초교육을 대학 지원사업 요건으로 지정
○○신문 · 발행 2026-09-29 · [원문](https://example.com) · 최신성 10 / 신뢰도 10 / 중요도 10 (평균 10.0)

① ○○부가 AI 중심 대학 18곳을 선정하고 대학당 연 30억 원을 지원한다고 발표했다.
② 선정 대학은 전교생 AI 기초교육과 전공 융합 교과목을 의무로 운영해야 한다.
③ 미선정 대학도 다음 공모에 대비해 교양 AI 과목 체계를 미리 설계할 필요가 있다.

(5건 반복)

## 선별 과정
- 제외: △△대 파일럿(평균 9.0점, 단일 강좌), □□ 보도(발행일이 기간 밖)
- 확인 필요: 원문을 열지 못한 기사 1건

## 핵심 키워드
- `AI 보편교육`: 전공과 무관하게 전교생이 AI 기초를 배우는 흐름
- `가치 검증`: AI 도입 여부보다 실제 효과를 따지는 단계로 이동
```

요청에 따라 형식이 달라집니다.
- **리포트**: 5선 뒤에 트렌드 분석, 약한 신호, 대학에 주는 권고가 붙습니다.
- **사례 표**: 모든 행에 발행일과 출처 링크가 달립니다. 사례가 다양하면 유형(유료 전교 라이선스, 무료 번들, 학생 프로모션 등)별로 서비스 범위를 비교합니다.
- **1페이지 뉴스레터**: 검증 흔적(건수, 사례별 날짜·링크·점수)을 남긴 채로 짧게 압축합니다.

어떤 형식이든 핵심 키워드가 마지막에 옵니다.

## 사용 시 유의사항

- 결과물은 웹 검색 시점의 자료를 바탕으로 합니다. 회의나 공문에 인용하기 전에 원문 링크를 한 번 더 확인하세요.
- 유료 매체는 원문을 열지 못할 수 있습니다. 이런 기사는 신뢰도 점수가 낮아져 5선에서 빠집니다.
